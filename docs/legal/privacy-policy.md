## 1. はじめに

本プライバシーポリシーは、［運営者名］（以下「当社」といいます）が提供する「Social Link AI」（以下「本サービス」といいます）における、ユーザーの情報の取り扱いについて定めるものです。

## 2. 取得する情報

本サービスは、以下の情報を取得します。

| 分類 | 内容 |
|---|---|
| アカウント情報 | メールアドレス、ユーザー名、パスワード（ハッシュ化して保存し、当社を含め誰も元のパスワードを閲覧できません） |
| 声紋データ | ユーザー本人の声の特徴を数値化した情報（埋め込みベクトル）。**元の音声そのものは保存しません**。この数値化処理は当社サーバー内で完結し（オープンソースの話者識別モデルをローカル推論）、外部の事業者に音声や声紋データを送信することはありません |
| 会話の音声 | 会話サポート機能利用時に録音される、ユーザーおよび会話相手の音声。**解析処理が完了次第、直ちに削除し、保存しません** |
| 会話の分析結果 | 音声から得られたテキスト（発言内容）、話題、会話の流れ、相手の反応、関係性の距離感、次に話すと良いことの提案など |
| 発言チェックの内容 | 発言案として入力されたテキストと、その判定結果 |
| 体調・気分等の記録 | 体調（4段階）、気分・不安度（0〜10）、次回目標、メモ |
| 場面の選択履歴 | 会話サポート利用時に選択した場面（学校・大学／職場／初対面／友人との会話／恋愛・気になる人） |

### 2.1 会話相手（第三者）の情報について

本サービスの性質上、ユーザーの会話の相手の音声・発言内容・感情の推定結果も取得・解析の対象となります。これらは会話の分析に必要な範囲でのみ処理され、独立した形で第三者の個人を特定する目的には利用しません。会話相手への説明・同意取得は、利用規約に定めるとおりユーザーの責任において行っていただく必要があります。

## 3. 利用目的

取得した情報は、以下の目的にのみ利用します。

1. 本サービスの各機能（会話の分析レポート、次の発言の提案、発言チェック、振り返り、体調・気分の記録）を提供するため
2. **声紋データは、会話中の発話がユーザー本人のものか会話相手のものかを区別する目的にのみ使用します。これ以外の目的（例：他サービスへの提供、広告への利用、本人以外の識別）には一切使用しません。**
3. アカウントの認証、パスワード再設定等のセキュリティ確保のため
4. サービス改善のための統計的な分析（個人を特定しない形に加工した上で実施）

## 4. 音声データの取り扱いと保存期間

- **生の音声データは、解析処理の直後に自動的に削除されます。** サーバー上に永続的な形では保存しません。処理中に予期せぬ障害が発生し即時削除に失敗した場合に備え、削除し忘れが残っていないかを定期的（30分ごと）に確認し、確実に削除する仕組みも設けています。
- 音声認識を委託する事業者（下記5.）に対しても、音声データや認識結果をその事業者側でログとして保存しないよう明示的に指定（オプトアウト）した上で送信しています。
- 声紋データ（埋め込みベクトル）は、ユーザーが声紋の再登録または削除を行うまで保存されます。
- 会話の分析結果（テキストベースのデータ）は、**「記録する」操作（体調・気分の記録画面での保存）を行わないまま一定時間（3時間）が経過すると、自動的に削除されます。**
- ユーザーが「記録する」操作を行った会話については、その振り返り内容・記録データを、**ユーザーが削除するか、アカウントを削除するまで保存**します。

## 5. 外部への提供・業務委託

本サービスは、以下の外部事業者に処理を委託しており、必要な範囲でデータを送信します。委託先は、当社が定める水準の安全管理措置を講じている事業者を選定します。

- 音声認識・話者分離・声の感情解析：株式会社アドバンスト・メディア「AmiVoice」（国内事業者。音声データはログとして保存しないよう設定した上で送信します）
- 会話内容の解釈・レポート生成：Anthropic社のClaude API
- メール配信（パスワード再設定・ユーザー名再通知）：Resend
- ホスティング・インフラ：個人開発フェーズにつき現時点では未選定です。商用化にあたって選定した時点で本ポリシーを更新します。

上記のうちAnthropic社・Resendは、日本国外にサーバーを置く事業者です。国外にある第三者への提供にあたっては、適用法令に従って適切な措置を講じます。

当社は、法令に基づく場合を除き、ユーザーの同意なく上記以外の第三者に個人データを提供しません。

## 6. ユーザーの権利

ユーザーは、当社が保有する自己の情報について、開示・訂正・削除を求めることができます。また、アカウントを削除することで、関連するデータ（声紋データ、記録データ等）を削除できます。ご希望の場合は、［連絡先メールアドレス］までご連絡ください。

## 7. セキュリティ

- パスワードは、Argon2という現時点で強固とされる方式のハッシュ関数を用いて保存しており、当社を含め誰も元のパスワードを復元できません。
- パスワード再設定は、有効期限付き・使い切りのリンクを介して行います。
- 通信は暗号化（HTTPS/TLS）された経路で行います。
